## 생성·검수 기록

허용된 workspace 밖의 배치 스킬 경로는 접근 거절 뒤 우회하지 않았다. 연결된 Codex의 built-in `image_gen` 개별 생성으로 새 PNG를 만들고, 도구가 반환한 해당 작업의 생성 파일만 공개 자산 경로에 복사했다. 중간 I02의 base64 수동 저장 시도는 불완전 PNG로 판정해 채택하지 않았다. API 키·외부 SDK·결정론적 SVG 폴백을 사용하지 않았다.

I01의 연결 표현과 I02의 누락 요건에는 각각 한 차례 표적 수정을 수행했다. I03·I04의 원본 검수 중 잘못 축약된 파일명으로 생긴 확인 실패는 정확한 전체 경로를 다시 열어 해소했으며, 그림 자체를 수정한 것으로 기록하지 않았다. 최종 네 장은 핵심 의미 검수 PASS다. 390px 화면에서 일부 보조 라벨은 확대가 필요하며 본문에도 동일한 조건·예외를 텍스트로 제공한다. 완벽한 모바일 소형 글자 가독성을 주장하지 않는다.
