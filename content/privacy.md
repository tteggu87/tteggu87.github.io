tteggu의 지식창고(이하 “사이트”)는 방문 통계 확인, 콘텐츠 개선, 광고 제공과 댓글 기능을 위해 아래와 같은 외부 서비스를 사용할 수 있습니다. 사이트 운영자는 필요한 범위에서만 정보를 처리하며, 방문자의 개인정보를 직접 판매하지 않습니다.

## 1. 처리될 수 있는 정보와 목적

- **접속 정보**: IP 주소, 브라우저·기기 정보, 방문한 페이지, 유입 경로, 접속 시각 등이 자동으로 처리될 수 있습니다.
- **이용 통계**: 방문 수, 페이지 이용 흐름과 콘텐츠 성과를 파악해 사이트를 개선하는 데 사용합니다.
- **광고 제공**: Google AdSense 광고가 게재되는 경우 쿠키 또는 유사 기술이 광고 제공, 빈도 관리와 성과 측정에 사용될 수 있습니다.
- **댓글**: 댓글을 작성하면 Giscus가 GitHub 계정과 GitHub Discussions를 이용해 댓글을 저장하고 표시합니다.

## 2. 사용하는 외부 서비스

### Google Analytics

사이트는 Google Analytics 4를 사용해 익명화·집계된 방문 통계를 확인합니다. Google이 파트너 사이트의 정보를 처리하는 방식은 [Google의 파트너 사이트 또는 앱 사용 시 데이터 처리 안내](https://policies.google.com/technologies/partner-sites?hl=ko)에서 확인할 수 있습니다. 방문자는 [Google Analytics 차단 브라우저 부가기능](https://tools.google.com/dlpage/gaoptout?hl=ko)을 사용할 수 있습니다.

### Google AdSense

Google AdSense 광고가 승인되어 게재되는 경우 Google과 광고 파트너는 쿠키를 이용해 광고를 제공하거나 측정할 수 있습니다. 맞춤 광고 설정은 [Google 광고 설정](https://adssettings.google.com/)에서 관리할 수 있습니다.

### Giscus와 GitHub

사이트의 댓글은 Giscus와 GitHub Discussions를 기반으로 작동합니다. 댓글 작성에는 GitHub 로그인이 필요하며, 댓글 내용과 계정 정보는 GitHub의 정책에 따라 처리됩니다. 자세한 내용은 [GitHub 개인정보처리방침](https://docs.github.com/ko/site-policy/privacy-policies/github-general-privacy-statement)을 확인해 주세요.

## 3. 쿠키와 선택권

브라우저 설정에서 쿠키를 삭제하거나 차단할 수 있습니다. 쿠키를 차단해도 글은 읽을 수 있지만, 일부 분석·광고·댓글 기능이 정상적으로 작동하지 않을 수 있습니다. Google 서비스 전반의 개인정보 보호 방식은 [Google 개인정보처리방침](https://policies.google.com/privacy?hl=ko)에서 확인할 수 있습니다.

## 4. 보유 기간과 국외 처리

사이트 운영자가 별도의 회원 데이터베이스를 직접 운영하지는 않습니다. 자동 수집 정보와 댓글의 보유 기간, 저장 위치 및 국외 처리 여부는 각 외부 서비스 제공자의 설정과 정책을 따릅니다. 댓글은 작성자가 GitHub에서 수정하거나 삭제할 수 있습니다.
