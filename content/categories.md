# 카테고리

이 블로그의 글을 두 가지 방식으로 탐색할 수 있습니다. **폴더 카테고리**는 글을 하나의 시리즈나 구조로 묶고, **태그 카테고리**는 서로 다른 폴더에 있는 글을 공통 주제로 연결합니다.

## 📁 폴더 카테고리

Quartz의 FolderPage가 실제 폴더 구조를 기준으로 목록을 만들며, 폴더 안의 글은 하나의 카테고리 흐름으로 읽을 수 있습니다.

- [[notes/온톨로지/|온톨로지]] — 온톨로지, 의미 계약, 지식그래프, 문맥 컴파일과 에이전트 검증을 연결한 시리즈입니다.
- [[notes/|전체 노트]] — 모든 발행 노트를 폴더 구조와 함께 탐색합니다.

## 🏷️ 태그 카테고리

Quartz의 TagPage가 글의 태그를 기준으로 목록을 만들며, 한 글이 여러 주제에 동시에 포함될 수 있습니다.

- [[tags/AI에이전트|AI 에이전트]] — 에이전트의 메모리·계획·실행·검증 구조를 다룹니다.
- [[tags/RAG|RAG]] — 검색증강생성, GraphRAG, 검색 경로와 문맥 활용을 다룹니다.
- [[tags/GraphRAG|GraphRAG]] — 그래프 기반 검색, 라우팅과 검색 중단 조건을 다룹니다.
- [[tags/지식그래프|지식그래프]] — 그래프 구조, 관계, 탐색과 지식 표현을 다룹니다.
- [[tags/딥리서치|딥리서치]] — 가설·반례·재검색과 근거 검증을 반복하는 조사 방법을 다룹니다.
- [[tags/|전체 태그]] — 더 세부적인 주제와 교차 분류를 탐색합니다.
